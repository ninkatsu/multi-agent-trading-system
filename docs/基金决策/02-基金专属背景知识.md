## 概念1：基金类型——风险收益的天花板

**①本质**：基金按投什么分类型，**类型基本决定了风险和收益的天花板**。选错类型比选错基金更致命。

**②图（风险-收益阶梯）**：
```
   收益潜力 ↑
            │  股票型/QDII海外       波动大，可能年化+30%/-30%
            │  偏股混合型            年化+15%/-20%
            │  平衡混合型            年化+10%/-12%
            │  偏债混合型            年化+6%/-6%
            │  纯债基金              年化+4%/-2%
            │  货币基金(余额宝)      年化+2%，几乎不亏
            └──────────────────→ 风险 ↑
   
   铁律：收益预期越高，能承受的回撤必须越大。
        买股票型却受不了-20%回撤 = 一定割在低点。
```

**③场景**：你 30 岁、能扛波动、想博高收益 → 偏股混合/股票型。你 60 岁、要稳健 → 偏债/纯债。**先定类型，再在同类型里挑基金**——跨类型比排名没意义（股票型第1和债基第1是两回事）。

**④对项目影响**：Risk Agent 的阈值必须**按基金类型动态设定**——偏股回撤限 12%、债基限 4%。这是改造里 Risk 的重要逻辑。

**⑤陷阱**：基金名字会骗人——"灵活配置混合"可能实际 90% 仓位股票（高风险），看类型更要看实际持仓。

## 概念2：净值（NAV）与估值——基金的"价格"

**①本质**：净值 = 基金每份额对应的资产价值。**你买卖基金就是按净值成交**。

**②公式 + 图**：
```
   单位净值 = (基金总资产 − 总负债) ÷ 总份额

   交易日  净值
   周一    2.100 ──╮
   周二    2.115   │  净值每天收盘后公布一次
   周三    2.090   │  普通基金一天只有一个数（无盘中K线！）
   周四    2.130 ──╯
   
   累计净值 = 单位净值 + 历史分红（看长期总回报用累计净值）
   估算净值 = 盘中根据重仓股涨幅"猜"今天净值（天天基金有，仅供参考）
```

**③场景**：你 15:00 前申购 005827，按**当天收盘净值**成交（当晚才公布）。如果 15:01 申购，按**次日**净值。所以盘中你看到的"估算净值"只是参考，**实际成交净值要等收盘**——这就是基金的"盲盒"特性。

**④对项目影响**：Execute Agent 必须按 15:00 切时间窗；Technical Agent 只能用日频净值（普通基金没有盘中价，ETF 除外）。

**⑤陷阱**：
- **不能看净值高低判断贵贱**：净值 5 元的基金不比净值 1 元的"贵"——净值只是起点不同，涨跌幅才重要。新基金净值 1 元不代表便宜。
- **估算净值会骗人**：盘中估算依赖"上次季报的重仓股"，若基金经理已调仓，估算就失真。

> 技术类比：净值像"每份额的资产快照"，每天收盘做一次快照。不像股价实时跳动。

## 概念3：申购/赎回与费率——买卖的真实成本

**①本质**：买基金叫"申购"，卖叫"赎回"，都要交费。**费率是基金的隐藏成本，长期吃掉收益**。

**②费率结构图**：
```
   买（申购）：
   申购费 = 金额 × 申购费率    通常 0~1.5%（平台常打1折）
   
   持有（每年扣，你感觉不到）：
   管理费 = 净值 × 1.5%/年（股票型）/ 0.5%（债基）   ← 每天从净值里扣
   托管费 = 净值 × 0.25%/年
   
   卖（赎回）：
   赎回费 = 持有时间越短费率越高（惩罚短期买卖）
        持有<7天：1.5%（狠罚！防短线）
        持有<1年：0.5%
        持有>2年：0%（很多基金免赎回费）
```

**③场景**：你买 10 万偏股基金，申购费 1.5%打1折=0.15% = ¥150；持有1年管理费+托管费 ~1.75% = ¥1750（每天悄悄扣）；持有时长不够赎回再扣 0.5% = ¥500。**一年下来光费率吃掉 2400+**，占 2.4%——如果基金只涨 5%，费率吃掉近一半。

**④对项目影响**：Execute Agent 的成本模型从"滑点"改成"费率"；Risk Agent 要把费率计入"持仓成本"，频繁申赎会被赎回费惩罚——**基金天然适合中长期持有，不适合像股票那样高频止损**。

**⑤陷阱**：
- **7 天内赎回 1.5% 重罚**：基金不适合做短线，决策时要把"持有期"纳入风控。
- **管理费是"无论亏赚都收"**：基金亏了经理照样收管理费，所以要看"超额收益"而非绝对收益。

## 概念4：A 类 vs C 类——同一个基金两种收费

**①本质**：同一只基金常分 A 类和 C 类，**策略一样，收费方式不同**。选错类白交钱。

**②对比图**：
```
                A 类                    C 类
   申购费      有（0~1.5%，常打折）    无（0）
   销售费      无                      有（每年0.4~0.8%，按天扣）
   赎回费      持有期递减，>2年免      持有期递减，>30天常免
   适合        长期持有（>1年）         短期持有（<1年）
   
   持有时间    A类总成本    C类总成本
   1个月       高(申购费)   低 ◀── 选C
   6个月       中           低 ◀── 选C
   1年         中           中  ── 持平
   3年         低 ◀── 选A   高(C每年扣销售费累积)
```

**③场景**：你打算买 005827 持有 3 年 → 选 A 类（申购费一次性，长期省）。你只想拿 3 个月试水 → 选 C 类（免申购费，销售费摊薄少）。

**④对项目影响**：Execute Agent 决策时要根据 Debate 给的"建议持有期"自动选 A/C 类——这是基金版独有的智能点。

**⑤陷阱**：C 类"免申购费"看着划算，但销售费**每年都扣**，持有越久越亏。别被"0申购费"骗成长期持有 C。

## 概念5：定投（定期定额）——基金的最佳打开方式

**①本质**：不一次性买入，而是**每隔固定时间投固定金额**。利用"净值高买少、净值低买多"摊薄成本。

**②图（微笑曲线）**：
```
   净值
   2.0 ┤  ●买5000（净值高，买2500份）    每次投同样多的钱：
   1.5 ┤      ●买5000（买3333份）        净值低 → 买到更多份额
   1.0 ┤          ●买5000（买5000份）    → 自动"低多高少"
   1.5 ┤              ●买5000（买3333份）
   2.0 ┤                  ●买5000（买2500份）
        └──────────────────→ 时间
   
   总投入 25000，总份额 16666，平均成本 = 25000/16666 = 1.50
   而净值从2.0→2.0没涨，但你通过定投在低位多买了，回弹到2.0就赚了
   = "微笑曲线"：先跌后涨，定投反而赚钱
```

**③场景**：2018 股市单边跌，一次性买入被套；定投者一路买在低位，2019 反弹后率先回本赚钱。**定投是"承认择时很难"的稳妥策略**，尤其适合波动大的偏股基金。

**④对项目影响**：这是基金版**新增的高价值能力**——Execution Agent 不只"买/不买"，而是输出"建议定投：每周¥2000，连投3个月"。Debate 的 HOLD 信号可转为"启动/继续定投"而非"不动"。

**⑤陷阱**：
- **定投不是无脑一直投**：牛市顶部定投会越投越亏，要在"高估时止盈"。
- **微笑曲线需要"先跌后涨"**：单边涨的行情，定投反而不如一次性买入（少赚）。定投适合"波动+长期向上"。

## 概念6：基金经理——基金的灵魂

**①本质**：主动型基金的业绩，**70% 取决于基金经理**。买主动基金本质是"买这个人"。

**②怎么评价一个经理**：
```
   维度              好经理的标准
   ─────────────────────────────────
   任职年限          >3年（经历过一轮牛熊）
   管理该基金时间    越长越能验证是他本人的能力
   历史年化          偏股 >12%、且跑赢基准
   历史最大回撤      可控（说明风控好）
   业绩稳定性        年度业绩排名不剧烈波动（不是赌徒）
   管理规模          别太大（>500亿难操作，船大难掉头）
   投资风格一致性    不会追热点乱切换（知行合一）
```

**③场景**：张坤管易方达蓝筹 8 年，年化 14%，重仓白酒港股——风格稳定、长期验证。某经理去年冠军今年垫底——大概率是赌对赛道运气，不是能力。**看"穿越牛熊的长期业绩"而非"单年冠军"**。

**④对项目影响**：这是基金版基本面 Agent 的**核心指标来源**——基金经理任期、历史年化、最大回撤、风格稳定性，全部进评分体系。

**⑤陷阱**：
- **冠军魔咒**：去年业绩第1的基金，今年常垫底（因为押注的风格轮动了）。别追冠军。
- **经理变更**：你买的"张坤的基金"，张坤离职后就不是那个东西了。**经理变更=必须重新评估**。

> 技术类比：基金经理 = 服务的核心 maintainer。一个项目的质量高度依赖主 maintainer 的水平和稳定性；maintainer 换人，项目性质就变了。

## 概念7：业绩比较基准——衡量"真本事"的尺子

**①本质**：每只基金都有个"业绩比较基准"（如"沪深300×80%+国债×20%"），**跑赢基准才是真本事**。

**②图**：
```
   收益
   15% ┤  ████  基金实际
   10% ┤  ███   业绩比较基准（沪深300）
        └─────
        超额 +5% = 基金经理的 Alpha（真本事）
        
   若基金涨8%、基准涨10% → 跑输2% → 这经理不如你直接买指数基金
   → 长期跑输基准的主动基金，不如买费率更低的指数基金
```

**③场景**：买主动基金就是相信经理能跑赢基准。如果某偏股基金 3 年都跑输沪深300，那不如直接买沪深300指数基金（费率低、不用赌经理）。

**④对项目影响**：基本面 Agent 要算"近1/3年相对基准的超额收益"作为核心评分项；回测基准从 SPY 换成对应基金基准。

**⑤陷阱**：基准是基金公司自己定的，有的故意定个容易超的基准"美化"业绩。看基准是否合理（是不是对应市场的真实指数）。

## 概念8：指数基金 vs ETF——被动投资

**①本质**：不靠经理选股，**完全复制一个指数**（如沪深300里的300只股票按比例买）。费率低、透明。

**②对比**：
```
              主动基金              指数基金/ETF
   选股        基金经理挑            跟着指数买（不挑）
   费率        1.5%/年               0.5%/年（ETF更低0.15%）
   目标        跑赢基准              复制基准（不追求超额）
   适合        信经理能力            信"市场长期向上"，省心省钱
   交易        申赎(T+1)             ETF可像股票一样盘中买卖(T+1)
```

**③场景**：巴菲特十年赌局——标普500指数基金 vs 一篮子对冲基金，指数赢了。**对大多数人，低费率宽基指数基金+定投，长期跑赢大多数主动基金**。

**④对项目影响**：指数基金/ETF 的"基本面 Agent"逻辑不同——不看经理选股能力，看"跟踪误差"（偏离指数多少）+ 指数本身估值。ETF 还能沿用股票技术面（有盘中价）。

**⑤陷阱**：行业指数基金（如"白酒指数"）波动极大，本质是赌一个行业，不是"分散投资"。别把行业指数当宽基用。

## 总览表（基金专属概念速查）

| 概念 | 本质 | 关键数 | 对项目的改造影响 |

## 把基金知识和改造方案串起来

```
你现在懂了：基金类型决定天花板 → 基金经理决定主动基金灵魂 →
            费率/A-C类/定投决定怎么买最划算 → 基准决定怎么评估 →

映射到改造后的6个Agent：
  基本面 = 基金经理 + 重仓 + 规模 + 跑赢基准否

  情绪面 = 中文新闻(GLM) + 申赎资金流向 + 评级
  辩论   = 复用
  风控   = 按类型阈值 + 费率成本 + T+1流动性

```
