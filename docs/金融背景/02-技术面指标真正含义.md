# 金融背景 02 · 技术面指标真正含义

> Technical Agent 看这些。核心转变：基本面问"值不值"，技术面问"**现在这个时点**该不该动手"。
> 技术面只看**价格和成交量的历史轨迹**（K线），不关心公司财报。固定结构：①本质 ②图 ③场景 ④本项目用法 ⑤陷阱。

---

## 大图：技术面在干嘛

```
   技术面 = 用历史价格/成交量图形，猜"接下来短期往哪走"
                          │
        ┌─────────────────┼─────────────────┐
        ▼                 ▼                 ▼
   【趋势方向】       【超买超卖】        【波动边界】
   MACD 均线差        RSI 强弱            布林带
   SMA 均线排列       （涨太多?跌太多?）  （价格正常波动范围）
   "现在在涨还是跌"   "该回调还是反弹"    "破位了没"
        │                 │                 │
        ▼                 ▼                 ▼
              配合【成交量】确认（放量=真，缩量=假）
                          │
                          ▼
                  技术评分 + BUY/SELL/HOLD
```

> 一句话：**技术指标是"价格的情绪温度计"——不预测基本面，只判断当前买卖力量的强弱和极端程度。**

---

## 先懂 K 线（一切的基础）

```
   一根 K 线 = 一天（或某周期）的四个价：
   
        ───  最高价
        │
       ┌─┐
       │ │  ← 实体：开盘→收盘
       │ │     红色(涨)：开在下收在上
       └─┘     绿色(跌)：开在上收在下
        │
        ───  最低价

   把每天的 K 线排起来 = K 线图（蜡烛图），就是技术面的"源数据"
```

---

## 指标1：SMA 简单移动平均线

**①一句话本质**：过去 N 天收盘价的平均——把价格"磨平"，看清趋势方向。

**②图**：
```
   价格 ──────────────────────────────────
        ╲    ╱╲      SMA20（近20天均价，反应快）
         ╲  ╱  ╲   ╱
       SMA50════════════════════（近50天均价，反应慢，更稳）

   多头排列：价格 > SMA20 > SMA50  → 短期均线在上 → 上涨趋势
   空头排列：价格 < SMA20 < SMA50  → 短期均线在下 → 下跌趋势
```

**③场景**：苹果股价站上 20 日线、20 日线又站上 50 日线（多头排列）→ 趋势向上，技术面"BUY"。反之跌破两条线（空头排列）→ 趋势走坏。

**④本项目用法**：`多头排列 → +2；空头排列 → -2`

**⑤陷阱**：均线是**滞后**指标——它确认趋势时，趋势往往已走了一半。用它确认方向可以，用它抓最低点不可能。

---

## 指标2：MACD（趋势 + 转折信号）

**①一句话本质**：短期均线和长期均线的"差值"——差值放大说明短期在加速偏离长期（趋势加强），差值正负翻转就是**拐点**。

**②公式 + 图**：
```
   MACD线   = 12日EMA（快） − 26日EMA（慢）     ← 快慢线之差
   信号线   = MACD的9日平均                    ← MACD再磨平一次
   柱状图   = MACD − 信号线                    ← 本项目用的 MACDh

        ──────  MACD
         ────   信号线
         ▮▮▮    柱状图（MACDh）

   金叉：MACD 从下穿上信号线（柱状图从负转正）→ 买入信号
   死叉：MACD 从上穿下信号线（柱状图从正转负）→ 卖出信号
```

```
   价格           MACD柱
    ╱╲             ▮▮▮        ← 金叉后柱状图转正变大：上涨动能增强
   ╱  ╲      ──────╲ 
  ╱    ╲   ╱        ╲
              ▯▯▯              ← 死叉后柱状图转负：下跌动能增强
```

**③场景**：苹果 MACD 柱状图昨天还是 -0.5，今天变 +0.3（金叉）→ "下跌动能耗尽、上涨动能启动"→ 技术面买入信号。但若柱状图已在高位且开始缩短 → 上涨在减弱，要小心。

**④本项目用法**：`金叉(柱>0且上升) → +2；死叉(柱<0且下降) → -2`

**⑤陷阱**：震荡市里 MACD 会反复金叉死叉"打脸"——趋势指标在横盘时失效，**MACD 只在有明显趋势时好用**。

---

## 指标3：RSI（相对强弱，超买超卖）

**①一句话本质**：过去一段时间里，"涨的力量"占"涨跌总力量"的百分比。0~100。

**②公式 + 图**：
```
   RSI = 涨幅平均 ÷ (涨幅平均 + 跌幅平均) × 100

   100 ───────── 超买区（>70）
                 涨太多了，短期可能回调 ↘
    70 ──────────────────────────
    50 ── 中性 ──────────────────
    30 ──────────────────────────
                 跌太多了，短期可能反弹 ↗
     0 ───────── 超卖区（<30）
```

**③场景**：苹果连涨两周，RSI 冲到 78 → "超买"——不是说明天必跌，而是说"涨得有点过分，回调概率升高"。反之 RSI 跌到 25 → "超卖"，可能跌过头了，反弹在即。

**④本项目用法**：
```
   30~70 正常 → +1
   <30 超卖（可能反弹）→ +2   ← 别吃惊：跌过头反而是买点
   >70 超买（可能回调）→ -2   ← 涨过头反而是风险
```

**⑤陷阱（最重要）**：**"超买不等于立刻卖"**。强趋势里 RSI 可以在 70 以上挂很久（"超买再超买"），你一卖就踏空。RSI 是"温度计"不是"开关"，要结合趋势（MACD/均线）用——趋势向上时的超买，比趋势向下时的超买安全得多。

> 技术类比：RSI 像 CPU 占用率——95% 不代表马上崩，但持续 100% 风险在累积；要结合负载类型（趋势）判断。

---

## 指标4：布林带（Bollinger Bands）

**①一句话本质**：用"均线 ± 2 倍标准差"画出价格**正常的波动通道**——触及上下轨意味着"走极端了"。

**②图**：
```
   价格
     │      ╭─── 上轨（均值+2σ）  ← 触上轨=偏贵/超买
     │   ╱─╮     
     │  ╱  ╲╱╲  ╱╲   ← 价格在通道内波动算"正常"
     │ ╱        ╲╱
     │      ╶── 中轨（20日均线）
     │   ╲─╮
     │      ╰─── 下轨（均值-2σ）  ← 触下轨=偏便宜/超卖
     └──────────────── 时间

   通道收窄（缩口）→ 波动率低，可能在酝酿大行情
   通道张开（开口）→ 波动加剧，趋势启动
```

**③场景**：苹果股价跌到布林带下轨 → "相对近期算便宜了"，可能反弹；涨破上轨 → "偏热"。如果带子突然收得很窄 → 暴风雨前的宁静，可能要选方向。

**④本项目用法**：`触下轨 → +2（超卖）；中轨附近 → +1；触上轨 → -1（超买）`

**⑤陷阱**：**"触轨"不是"反转"**。强趋势里价格会"贴着上轨走"很久，你一摸上轨就做空会被碾碎。布林带判断"极端"靠谱，判断"转向"要配合成交量和其他指标。

---

## 指标5：成交量（Volume）——测谎仪

**①一句话本质**：这一天交易了多少股。**价格能骗人，成交量难骗人**——它是验证价格信号真假的"测谎仪"。

**②图 + 口诀**：
```
   放量上涨：价涨 + 量明显放大 → 真涨（有钱在追）  → +1
   缩量上涨：价涨 + 量萎缩     → 假涨（没人跟）    → 警惕
   放量下跌：价跌 + 量放大     → 真跌（恐慌抛售）  → -2（最危险）
   缩量下跌：价跌 + 量萎缩     → 假跌（没人卖）    → 可能见底
```

**③场景**：苹果突破前高，但当天成交量比平时还小 → "无量突破"，大概率假突破要回落。反之放量突破 → 真突破，可追。

**④本项目用法**（`technical_agent.py`）：
```python
vol_avg = df["Volume"].rolling(20).mean().iloc[-1]   # 20日均量
if vol_current > vol_avg * 1.5:  volume_trend = "HIGH"   # 放量
elif vol_current < vol_avg * 0.5: volume_trend = "LOW"   # 缩量
```

**⑤陷阱**：成交量要和**价格方向**配对看才有效。单看"放量"没用——放量涨和放量跌是天壤之别。

---

## 总览表

| 指标 | 本质 | 买信号 | 卖信号 | 最大陷阱 |
|------|------|--------|--------|---------|
| SMA | 趋势方向 | 多头排列 | 空头排列 | 滞后，抓不到顶底 |
| MACD | 趋势动能/拐点 | 金叉 | 死叉 | 横盘市反复打脸 |
| RSI | 超买超卖 | <30超卖 | >70超买 | 超买可挂很久，别见超买就卖 |
| 布林带 | 波动通道 | 触下轨 | 触上轨 | 趋势中会贴轨走 |
| 成交量 | 信号测谎 | 放量涨 | 放量跌 | 必须配价格方向看 |

---

## 一句话串起来（场景复盘）

> 苹果：SMA 多头排列(+2)、MACD 金叉(+2)、RSI 78 超买(-2)、价格贴布林上轨(-1)、放量上涨(+1)。
> → 技术面结论：**趋势向上且动能强，但已明显超买、贴上轨**。所以技术 Agent 可能给"中高分但提示短期回调风险"——这正是辩论里 Bear 攻击 Bull"现在追高很危险"的弹药来源。

> **基本面和技术面打架，是常态不是 bug**——好公司 + 坏时机，正是 Debate 存在的意义。
