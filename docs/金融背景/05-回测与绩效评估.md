# 金融背景 05 · 回测与绩效评估

> `backtest/backtester.py` 在干这件事。前面所有 Agent + 风控，只是"一套决策逻辑"。**回测 = 把这套逻辑扔到历史数据上跑一遍，看它过去能不能赚钱、赚得稳不稳。**
> 这是金融版的"上线前压测"。

---

## 大图：回测在干嘛

```
   历史数据 (AAPL 2025-01 ~ 2025-08，每天一根K线)
        │
        ▼
   ┌─────────────────────────────────────────┐
   │  逐日遍历：                              │
   │   ① 算当天技术指标(MACD/RSI/...)         │
   │   ② 生成信号(BUY/SELL/HOLD)             │
   │      (回测用简化规则，省LLM调用成本)     │
   │   ③ 按信号模拟交易(买入/卖出/止损)       │
   │   ④ 记录每天组合净值 → 净值曲线          │
   └─────────────────────────────────────────┘
        │
        ▼
   ┌─────────────────────────────────────────┐
   │  算绩效指标：                            │
   │   年化收益 / 夏普 / 索提诺 / 最大回撤    │
   │   胜率 / 盈亏比 / 超额收益(vs基准SPY)    │
   └─────────────────────────────────────────┘
        │
        ▼
   判断策略好不好 + 发现陷阱
```

> 一句话：**回测 = 用历史当实验室，回答"这套决策逻辑在过去能不能赚、多稳、最惨多惨"。**

---

## 核心概念1：净值曲线（Equity Curve）

**①本质**：每天你的总资产画成一条线。**最直观的成果图**。

**②图**：
```
   净值
   1.20 ┤              ╱──╲        ╱──  最终1.134（赚13.4%）
   1.15 ┤         ╱──╱     ╲    ╱
   1.10 ┤    ╱──╱            ╲╱
   1.05 ┤ ╱
   1.00 ┤╱ 起点（初始100万）
        └────────────────────────── 时间(8个月)
        
   一条向上的线 = 赚钱；越平滑 = 越稳；
   大起大落的线 = 收益高但拿不住
```

**③场景**：项目回测 AAPL 8 个月，初始 100 万 → 最终 113.4 万，年化 13.4%。曲线整体向上，中间有回撤（那段下凹就是亏的时候）。

---

## 核心概念2：年化收益率（Annualized Return）

**①本质**：折算成"一年能赚百分之几"，方便跨周期比较。

**②公式**：
```
   年化 = (1 + 总收益) ^ (252 / 交易天数) − 1
   
   回测 8 个月(~168 交易日)，总收益 13.4%
   年化 = 1.134 ^ (252/168) − 1 ≈ 20%+
   
   252 = 一年大约的交易天数（美股），用来把任意周期折算成年
```

**③场景**：8 个月赚 13.4% 听着一般，但年化后 ~20% 就很可观了。**年化是"统一度量衡"**——8个月13%和3年50%哪个好？年化一下才能比。

**④陷阱**：短期回测的年化是"外推"，8个月好不代表年年这么好。

---

## 核心概念3：基准与超额收益（Alpha）

**①本质**：你的策略赚了 13.4%，但如果同期大盘(标普500/SPY)涨了 10%，那你的"真本事"只有 3.4%——**超额收益**。

**②图**：
```
   收益
   13.4% ┤ ████  你的策略
   10.0% ┤ ███   基准 SPY(大盘)
        └────────
        超额 = 13.4% - 10% = +3.4%  ← 这才是你策略的"Alpha"(真本事)
```

**③场景**：牛市里猪都能飞——大盘涨 30%，你策略涨 32%，别吹自己厉害，你只跑赢 2%。**不跟基准比的都是耍流氓**。基准怎么选？美股用 SPY，A股用沪深300，基金用对应指数。

**④陷阱**：超额收益也可能是运气/过拟合，要结合夏普和样本量看。

> 技术类比：基准 = baseline。你的 A/B 实验提升 5%，但如果大盘本身涨了 20%，那点提升可能只是搭了顺风车。Alpha 是"剔除市场 Beta 后剩下的真本事"。

---

## 核心概念4：胜率与盈亏比（Win Rate & Profit Factor）

**①本质**：
- **胜率**：盈利交易占总交易的比例。
- **盈亏比**：平均每次赚的 ÷ 平均每次亏的。

**②图**：
```
   策略A：胜率 90%，但每次赚1块、亏10块 → 10次：赚9次=+9，亏1次=-10 → 还是亏!
   策略B：胜率 40%，每次赚3块、亏1块   → 10次：赚4次=+12，亏6次=-6  → 赚+6
   
   → 胜率高 ≠ 赚钱！盈亏比同样重要。
   → 趋势策略常是"低胜率+高盈亏比"(亏小赚大)，震荡策略常是"高胜率+低盈亏比"
```

**③场景**：项目回测胜率 62%、盈亏比 1.5:1 → 两个都不错，正期望。**真正决定赚不赚的是"期望值"= 胜率×平均赚 − 败率×平均亏，必须为正**。

**④陷阱**：新手只盯胜率，被"高胜率"策略坑——那种策略往往靠"小赚多次+偶尔巨亏"，一次巨亏吃掉所有利润。

---

## 核心概念5：夏普/索提诺（见 04 详述）

回测里这两个指标看"性价比"，不再重复。记住：**年化收益看赚钱能力，夏普看赚钱的稳定性/性价比，最大回撤看最惨时刻**。三者组合才完整。

---

## ⚠️ 三大回测陷阱（这一节比指标更重要）

> 回测最容易"自欺欺人"。一个回测漂亮的策略实盘可能血亏，几乎都是栽在这三个陷阱上。

### 陷阱1：过拟合（Overfitting）——把噪音当规律

```
   你在历史数据上调参，发现"RSI<31.7 且 MACD柱>0.3 时买"回测暴赚。
   
   但这个 31.7 和 0.3 是你试出来的，恰好"拟合"了这段历史的噪音。
   未来不会重复这些噪音 → 实盘失效。
   
   症状：参数越精细、回测越完美，越可疑。
   解药：样本外测试(留一段没参与调参的数据验证)、参数别调太细、逻辑要讲得通。
```

> 技术类比：过拟合 = 训练集准确率 99% 但测试集 60%。回测 = 训练集，实盘 = 测试集。

### 陷阱2：前瞻偏差（Look-ahead Bias）——用了当时不可能知道的信息

```
   错误示范：用"今天的收盘价"决定"今天的买入价" → 但收盘时你才知道收盘价!
   错误示范：用全年财报数据回测，但财报是季末才发布的，回测里却提前用了。
   
   症状：回测收益好得离谱。
   解药：每个决策点只能用"截至当时"已公开的数据。本项目用当天开盘/前一日收盘下单。
```

> 技术类比：前瞻偏差 = 用未来的 label 做特征。数据泄漏。回测里最隐蔽的 bug。

### 陷阱3：幸存者偏差（Survivorship Bias）——只拿活下来的公司测

```
   你用"现存的美股"回测，但退市的、破产的公司不在样本里。
   → 回测里全是"活下来的赢家"，自然表现好。
   → 实盘你买的可能是下一个退市的。
   
   症状：回测收益系统性偏高。
   解药：用包含退市股票的"点-in-time"全样本数据（专业数据才全，免费数据往往有此偏差）。
```

> 技术类比：幸存者偏差 = 只用还在线上运行的服务的监控数据做容量规划，忽略了已经挂掉的服务。

## 本项目回测的一个务实取舍

```python
# backtester.py 的 _generate_signal 用"简化规则"代替完整 Agent 决策
def _generate_signal(self, row, indicators, idx):
    if RSI<35 且 MACD金叉: return "BUY"
    if RSI>65 且 MACD死叉: return "SELL"
    return "HOLD"
```

**为什么不全用 LLM Agent 跑回测？**

```
   完整 Agent 回测：8个月×168天，每天调 6+ 个 LLM = 上千次 API 调用
   → 贵、慢、且 LLM 输出有随机性不可复现
   
   务实做法：
   - 用简化规则(确定性)做日常回测，快速验证策略骨架
   - 关键日期再用完整 Agent 跑决策
   
   工程启示：回测要"快、可复现、便宜"，LLM 的随机性反而是回测的敌人。
```

## 一句话串起来

> 回测告诉你：**这套策略在过去 8 个月，年化 13.4%、跑赢大盘 3.4%、最惨只回撤 7.2%、夏普 1.8**——看起来不错。但永远记住三个陷阱：这 13.4% 可能是过拟合出来的、可能用了未来信息、可能漏了退市股。**回测是必要不充分条件**——回测不好肯定不行，回测好也不一定行。

## 金融背景全篇总结（5 篇串起来）

```
基本面(01)：这公司值不值？      → 长期价值
技术面(02)：现在能不能动手？    → 短期时机
情绪面(03)：其他人怎么看？      → 预期差/反向
风控(04)：  怎么不被一次搞死？  → 安全底线
回测(05)：  过去到底行不行？    → 验证+防自欺

→ 这 5 块就是一套完整投资决策的知识闭环，也正是 6 个 Agent 的金融映射：
  3个分析师(01-03) → 辩论(综合) → 风控(04) → 执行 → 回测验证(05)
```
