# 金融背景 03 · 情绪面与市场心理

> Sentiment Agent 看这些。基本面看公司、技术面看价格，**情绪面看"人"**——市场其他人怎么看这只股票。
> 金融里有一句名言："市场短期是投票机，长期是称重机。"情绪面研究的就是那台"投票机"。

---

## 大图：情绪面三个信息源

```
              "其他人对这股票什么态度？"
                       │
        ┌──────────────┼──────────────┐
        ▼              ▼              ▼
   【大众情绪】    【聪明钱动向】   【专业判断】
   新闻/社媒NLP    机构持仓变化     分析师评级
   "散户在兴奋     "大资金在买      "研究员说
    还在恐慌"       还在撤"          买还是卖"
        │              │              │
        └──────────────┼──────────────┘
                       ▼
              情绪评分 + BUY/SELL/HOLD
```

> 一句话：**情绪面捕捉的是"预期差"——当所有人都觉得要涨时，反而危险（没人再买了）；当所有人都绝望时，反而有机会（该卖的都卖了）。**

## 概念1：新闻情绪（News Sentiment）

**①一句话本质**：用 NLP 给新闻标题打"正面/负面"分，看舆论风向。

**②怎么算**（本项目用 TextBlob）：
```
   每条新闻标题 → TextBlob → polarity ∈ [-1, +1]
   -1 = 极度负面，0 = 中性，+1 = 极度正面
   20 条新闻取平均 → 整体情绪分
```

```
   标题"苹果新品大卖，利润超预期"     → +0.6（正面）
   标题"苹果被反垄断调查"             → -0.5（负面）
   标题"苹果发布季度财报"             →  0.0（中性）
```

**③场景**：某只股票最近 20 条新闻平均情绪 +0.6（一片叫好）→ 但小心，这往往是"利好出尽"——好消息都消化了，该买的都买了，反而容易跌。反之情绪 -0.6（一片唱衰）→ 可能过度悲观，反而是逆向布局时机。

**④本项目用法**：
```
情绪 > 0.5  极度正面 → +2
0.1~0.5    正面     → +1
-0.1~0.1   中性     → 0
< -0.1     负面     → -1
< -0.5     极度负面 → -2
```

**⑤陷阱（关键）**：
- **TextBlob 对中文几乎无效**——它是英文情感词典。你做国内基金时，新闻是中文的，必须换成中文 NLP（如 SnowNLP）或直接让 LLM 判情绪。**这是基金改造必改点**。
- **情绪是反向指标**：极端乐观 = 顶部信号，极端悲观 = 底部信号。别把"情绪好"简单当"该买"。

> 技术类比：新闻情绪像应用商店评分——满屏五星反而可能是刷的/见顶，差评如潮里可能藏着抄底机会。要看"评分的极端程度"而非"评分高低"。

## 概念2：机构持仓变化（聪明钱）

**①一句话本质**：基金/投行等大机构在加仓还是减仓——**跟着聪明钱走**。

**②逻辑**：
```
   机构（公募/对冲/社保）= 信息、研究、资金都碾压散户的"聪明钱"
   他们在加仓 → 他们判断低估，未来可能涨
   他们在减仓 → 他们在撤，要警惕

   为什么聪明？机构有研究员蹲公司、有更快数据、能影响定价。
   散户跟机构不是"抄作业"，而是借机构的判断做交叉验证。
```

**③场景**：苹果季报显示，桥水、贝莱德等头部机构同时减持苹果 → "聪明钱在离场"。即使基本面技术面都还好，这也给 Bear 提供了强力弹药："大资金都在撤，你凭什么接盘？"

**④本项目用法**（简化版）：`yfinance` 取 `institutional_holders`，判断 ACTIVE/UNKNOWN，作为情绪参考。

**⑤陷阱**：
- 机构持仓数据**滞后**（按季度披露），你看到时机构可能早就动了。
- 机构也会错，也会被套。跟聪明钱是提高胜率，不是保赢。

## 概念3：分析师评级（专业判断）

**①一句话本质**：卖方分析师（券商研究员）给的"买入/持有/卖出"建议汇总。

**②评级体系**：
```
   Strong Buy 强烈买入  → +2
   Buy 买入             → +1
   Hold 持有            → 0
   Sell 卖出            → -1
   Strong Sell 强烈卖出 → -2
```

**③场景**：30 个覆盖苹果的分析师，25 个 Buy、5 个 Hold → 一致看多。但若最近 3 个月有 5 个分析师集中下调评级（Buy→Hold）→ "专业共识在松动"，是领先转弱信号。

**④本项目用法**：取 `stock.recommendations` 最新一期的 `To Grade`。

**⑤陷阱（重要）**：**分析师有"乐观偏差"**——投行分析师很少给 Sell（怕得罪上市公司、影响投行业务）。所以"全是 Buy"是常态，信息量低；**一旦出现 Sell 或集中下调，反而信号很强**（因为打破惯性需要勇气）。看"变化方向"比看"绝对评级"更有用。

## 概念4：恐贪指数（Fear & Greed Index）

**①一句话本质**：把多个情绪指标（波动率、动量、避险需求等）合成一个 0~100 的数，衡量**整个市场**现在是恐惧还是贪婪。

**②图**：
```
   0 ─────────── 25 ───── 50 ───── 75 ─────────── 100
   极度恐惧      恐惧    中性    贪婪      极度贪婪
   
   "别人恐惧我贪婪，别人贪婪我恐惧" —— 巴菲特
   极度恐惧(<25)：市场崩了，反而是捡便宜时机
   极度贪婪(>75)：市场疯了，反而要落袋为安
```

**③场景**：2020 年 3 月疫情暴跌，恐贪指数跌到 5（极度恐惧）——事后看那是绝佳买点。2021 年牛市顶，恐贪指数 90+——事后看是减仓时机。

**④本项目用法**：项目里是"简化实现"（注释提到 CNN Fear & Greed），实际未深度接入。**基金改造时可接入真实恐贪/A股情绪指数**。

**⑤陷阱**：恐贪指数是**市场整体**情绪，不是单只股票。极度恐惧时买"好公司"，而不是闭眼买任何股票。

## 核心金融原理：情绪面为什么有效？——预期差与反向指标

```
   价格 = 基本面价值 × 情绪扰动
          └─长期称重机─┘  └短期投票机┘

   当情绪把价格推得远高于价值（极度贪婪）→ 未来回归价值 = 跌
   当情绪把价格压得远低于价值（极度恐惧）→ 未来回归价值 = 涨

   这就是"预期差"：价格已计入过度乐观/悲观，真实情况没那么好/坏，
   差额就是你的盈利空间。
```

```
        价格
         │        ╱╲ ← 极度贪婪顶（情绪远超价值）→ 卖
         │      ╱    ╲
   价值 ═════╱════════╲════════════ ← 内在价值（基本面锚）
         │  ╱          ╲    ╱
         │╱              ╲╱ ← 极度恐惧底（情绪远低于价值）→ 买
         └──────────────────── 时间
```

> 这张图是情绪面的灵魂：**情绪让价格围绕价值摆动，摆到极端就是反向信号。**

## 总览表

| 信号源 | 看什么 | 乐观信号 | 悲观信号 | 陷阱 |
|--------|--------|---------|---------|------|
| 新闻情绪 | 标题NLP极性 | 正面 | 负面 | 中文需换NLP；极端是反向 |
| 机构持仓 | 大资金动向 | 加仓 | 减仓 | 数据滞后 |
| 分析师评级 | 专业建议 | Buy | Sell | 乐观偏差，看变化不看绝对 |
| 恐贪指数 | 市场整体情绪 | <25恐惧=买 | >75贪婪=卖 | 是整体不是个股 |

---

## 一句话串起来（场景复盘）

> 苹果：新闻情绪 +0.3（略正面 +1）、机构减持（-2）、分析师多为 Buy 但最近有下调（0）、恐贪指数 80（市场贪婪，整体偏危险）。
> → 情绪面结论：**舆论还行，但聪明钱在撤、市场整体过热**。这给 Bear 提供了"机构减持+市场贪婪"双重弹药，而 Bull 只能拿新闻正面说事——辩论天平倾向谨慎。

> 三个分析师到齐了：基本面说"好公司但贵"、技术面说"趋势好但超买"、情绪面说"聪明钱在撤"。三方信号互相矛盾，**这正是 Debate 节点要解决的——把矛盾吵明白再决策**。
