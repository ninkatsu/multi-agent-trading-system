# 金融背景 01 · 基本面指标真正含义

> Fundamental Agent 看的就是这些。每个指标按固定结构讲：**①一句话本质 ②图/公式 ③生动场景 ④本项目用法 ⑤陷阱**。
> 贯穿场景：要不要买苹果(AAPL)。

---

## 大图：基本面到底在看什么

```
                  "这公司值不值得拥有？"
                          │
        ┌─────────────────┼─────────────────┐
        ▼                 ▼                 ▼
   【赚钱能力】        【估值贵不贵】      【安全不安全】
   ROE 净资产收益率    PE 市盈率          资产负债率 D/E
   利润率              PB 市净率          自由现金流 FCF
   营收增长                                  （会不会断粮/倒闭）
        │                 │                 │
        └─────────────────┼─────────────────┘
                          ▼
                  综合评分(1-10) + BUY/SELL/HOLD
```

> 记住这条主线：**基本面 = "这公司本身好不好" + "现在价格划不划算" + "会不会出事"**。三件事。

---

## 指标1：PE（市盈率，Price-to-Earnings）

**①一句话本质**：你花多少年能靠利润"回本"。

**②公式 + 图**

```
PE = 股价 ÷ 每股利润（EPS）   =   公司总市值 ÷ 净利润

  例：苹果股价 $200，每股赚 $8 → PE = 25 → "按现在赚钱速度，25年回本"
```

```
  便宜 ←────────────── PE ──────────────→ 贵
   5        15        25        40        100+
  银行     成熟蓝筹   科技股    高增长    概念炒作
  (被嫌弃)  (合理)    (偏贵但   (预期高   (泡沫)
            合理)     增长快)
```

**③场景**：
- 苹果 PE 25，可口可乐 PE 25，看起来一样贵？不一定——苹果利润还在涨，可口可乐几乎不涨。**PE 要结合"增长"看**（见 PEG）。
- 一家亏损公司 PE 是负数或"NA"，PE 对它没意义（很多科技公司、基金里的成长股早期都这样）。

**④本项目用法**（`fundamental_agent.py` 评分规则）：
```
PE < 15  → +2（便宜）
15~25    → +1（正常）
> 25     → -1（偏贵）
```

**⑤陷阱**：
- **周期股陷阱**：钢铁/航运在景气顶点利润爆高 → PE 看着很低"好便宜" → 其实是周期顶，买完就跌。低 PE 反而是卖出信号。
- **负 PE**：亏损企业 PE 失效，别硬套规则。

## 指标2：PB（市净率，Price-to-Book）

**①一句话本质**：你花的钱，是公司"账面净资产"的几倍。

**②公式**：
```
PB = 股价 ÷ 每股净资产   =   市值 ÷ 净资产（股东权益）

  例：苹果每股净资产 $4，股价 $200 → PB = 50 → "你花 50 块买账面值 1 块的资产"
```

```
  PB < 1  → "破净"：市场觉得这公司不值账面价（常出现在银行/钢铁，可能低估，也可能烂）
  PB 1~3  → 正常
  PB > 5  → 市场愿意为"无形资产/品牌/成长"付高溢价（科技/消费龙头常见）
```

**③场景**：银行股常 PB 0.5（破净）——不是捡漏，是市场担心它坏账。苹果 PB 50——因为它的值钱东西（品牌、生态、IP）不在账面上。**PB 对重资产公司有用，对轻资产公司失真**。

**④本项目用法**：`PB < 1.5 → +2；1.5~3 → +1；> 3 → -1`

**⑤陷阱**：轻资产公司（软件、基金公司）净资产低 → PB 天然奇高，不代表贵。别用 PB 给苹果/微软下结论。

---

## 指标3：ROE（净资产收益率，Return on Equity）

**①一句话本质**：公司拿股东的钱，一年能赚出百分之几。**这是巴菲特最看重的指标**。

**②公式**：
```
ROE = 净利润 ÷ 净资产（股东权益）

  例：苹果净资产 700 亿，年净赚 1000 亿 → ROE ≈ 145%（极度优秀，杠杆+高利润）
  普通公司 ROE 10%~15%；> 20% 算优秀；> 30% 顶尖
```

```
  赚钱效率  低 ←──── ROE ────→ 高
            5%    15%   20%   30%+
           (平庸)        (优秀)(顶尖)
```

**③场景**：同样投 100 块，A 公司一年赚 5 块（ROE 5%，存银行都不如），B 公司一年赚 30 块（ROE 30%）。同样股价你当然买 B。**ROE 衡量"资本回报效率"，是区分好公司/烂公司的核心**。

**④本项目用法**：`ROE > 20% → +2；10~20% → +1；< 10% → -1`

**⑤陷阱（杜邦分解）**：ROE 高可能是真优秀，也可能是**借钱借出来的**。同样 ROE 20%：
- 净利率高（产品牛）→ 真好
- 杠杆高（借了一屁股债）→ 危险，下个指标 D/E 会抓它

> 技术类比：ROE 像服务的"资源利用率"——高利用率可能是优化得好，也可能是机器快撑爆了，要拆开看。

---

## 指标4：营收增长（Revenue Growth）

**①一句话本质**：公司收入一年涨了百分之几——**成长性**。

**②公式**：`营收增长 = (今年营收 - 去年营收) ÷ 去年营收`

**③场景**：
- 苹果营收增长 2% → 成熟期，稳但没想象力，估值给不高。
- 某新能源车营收增长 50% → 高成长，市场愿给高 PE（因为"未来会赚更多"）。
- 增长 -10% → 收缩，警惕。

**④本项目用法**：`> 20% → +2；5~20% → +1；< 5% → -1`

**⑤陷阱**：增长是"营收"不是"利润"。有的公司营收猛涨但亏更多（烧钱换规模），增长好看不等于赚钱。

---

## 指标5：利润率（Profit Margin）

**①一句话本质**：卖 100 块钱的东西，真正落袋多少。

**②公式**：`利润率 = 净利润 ÷ 营收`

```
  苹果利润率 ~25%：卖 100 块，净赚 25 块（消费品里恐怖的高）
  普通制造业 5%：卖 100 块赚 5 块
  超市 2%：薄利多销
```

**③场景**：利润率高 = 有"定价权"（敢卖贵还有人买），是护城河的体现。苹果能赚 25% 因为生态锁定；普通家电只能赚 3% 因为同质化内卷。

**④本项目用法**：`> 20% → +2；10~20% → +1；< 10% → -1`

**⑤陷阱**：利润率会随周期波动。原材料涨价、降价促销都会压低利润率，要看趋势而非单点。

---

## 指标6：资产负债率（Debt-to-Equity, D/E）

**①一句话本质**：公司借的钱是股东钱的几倍——**杠杆/安全垫**。

**②公式**：`D/E = 总负债 ÷ 股东权益`

```
  D/E 0.5：借 5 块，自己有 10 块 → 稳
  D/E 1.0：借 10 块，自己 10 块 → 适中
  D/E 2.0+：借 20 块，自己 10 块 → 激进，利率一涨就危险
```

**③场景**：2008 雷曼 D/E 极高 → 危机一来资金链断裂破产。苹果 D/E 1.5 左右但现金流极强，举债是为回购股票避税，性质不同。**D/E 高 + 现金流弱 = 定时炸弹**。

**④本项目用法**：`< 0.5 → +1；0.5~1 → 0；> 1 → -1`

**⑤陷阱**：行业差异巨大。银行 D/E 天然极高（就是借钱放贷的），不能用这个规则套银行。**指标永远要同行业比**。

---

## 指标7：自由现金流（FCF，Free Cash Flow）

**①一句话本质**：公司赚的钱里，扣完维持生意必须的投资后，**真正能自由支配的现金**。

**②公式**：
```
FCF = 经营现金流 − 资本性支出（买设备/建厂房等）

  正值 → 有"余粮"：可分红、回购、过冬
  负值 → 在烧钱或重投入：要么扩张期，要么吃老本快断粮
```

**③场景**：亚马逊早期 FCF 负但营收猛增（主动重投入扩张，好事）；某传统零售 FCF 负且营收不涨（真在失血，坏事）。**FCF 负不一定是坏事，要看钱花在哪**。

**④本项目用法**：`正值 → +1；负值 → -1`

**⑤陷阱**：FCF 是"现金"视角，利润是"会计"视角——有的公司账面盈利但收不回钱（应收账款堆着），FCF 会先露出马脚。**利润能粉饰，现金流难造假**。

## 总览表（背这张就够应付基本面）

| 指标 | 本质 | 好的标准 | 主要陷阱 |
|------|------|---------|---------|
| PE | 几年回本 | <15 便宜 | 周期股低PE是顶、亏损失效 |
| PB | 买账面值几倍 | <1.5 | 轻资产公司失真 |
| ROE | 资本回报效率 | >20% | 可能是借出来的（看D/E） |
| 营收增长 | 成长性 | >20% | 营收涨≠利润涨 |
| 利润率 | 定价权/护城河 | >20% | 随周期波动 |
| D/E | 杠杆/安全 | <0.5 | 行业差异大，别跨行业比 |
| FCF | 真余粮 | 正值 | 负值要看是扩张还是失血 |

---

## 一句话串起来（场景复盘）

> 苹果：PE 25（偏贵 -1）、PB 50（对轻资产失真，别太扣分）、ROE 145%（顶尖 +2）、营收增长 2%（缓慢 -1）、利润率 25%（优秀 +2）、D/E 1.5（适中 0）、FCF 正（+1）。
> → 基本面结论：**这是一家极赚钱的顶尖公司，但增长已放缓、估值不便宜**。所以基本面 Agent 大概率给"中高分 + BUY但别追高"——这和你后面会看到的"辩论里 Bull 拿它当王牌、Bear 拿估值和增长说事"完全对得上。
